# Tidepool

An interactive ocean micro-site in a single HTML file.

- Stir the sea with your finger or mouse: a real-time WebGL fluid simulation warps the whole scene, including the headline text.
- "Take the plunge" dives from a sunset shore to an underwater pearl garden.
- Tap the five glowing bubbles to collect their pearls; finish the quest for the necklace finale.

No build step and no dependencies (fonts load from Google Fonts). Open `index.html` in any modern browser, phone or desktop.
